# AwadyLab Packages

Documentation and runnable samples for the AwadyLab .NET packages published on NuGet.
Each folder holds a package family's README, its license and, where there is one, a `SampleApp` that consumes
the published NuGet packages.

| Family | Packages | Sample |
| --- | --- | --- |
| [AwadyLab.ConfigurationUtilities](AwadyLab.ConfigurationUtilities) | [![NuGet](https://img.shields.io/nuget/v/AwadyLab.ConfigurationUtilities.svg)](https://www.nuget.org/packages/AwadyLab.ConfigurationUtilities) | ASP.NET Core app showing validation, encryption, overrides and polymorphic binding |
| [AwadyLab.EFCatalyst](AwadyLab.EFCatalyst) | [![NuGet](https://img.shields.io/nuget/v/AwadyLab.EFCatalyst.svg)](https://www.nuget.org/packages/AwadyLab.EFCatalyst) `.Abstraction` `.SqlServer` `.PostgreSql` `.Sqlite` | Console app running one scenario per feature on SQLite |
| [AwadyLab.HttpKit](AwadyLab.HttpKit) | [![NuGet](https://img.shields.io/nuget/v/AwadyLab.HttpKit.svg)](https://www.nuget.org/packages/AwadyLab.HttpKit) `.AspNetCore` `.Testing` | ASP.NET Core app with generated typed clients and fixture-based testing |
| [AwadyLab.Mediator](AwadyLab.Mediator) | [![NuGet](https://img.shields.io/nuget/v/AwadyLab.Mediator.svg)](https://www.nuget.org/packages/AwadyLab.Mediator) `.RabbitMQ` `.Redis` | Two services exchanging notifications over RabbitMQ and Redis (docker-compose) |
| [AwadyLab.MoreExtensions](AwadyLab.MoreExtensions) | [![NuGet](https://img.shields.io/nuget/v/AwadyLab.MoreExtensions.svg)](https://www.nuget.org/packages/AwadyLab.MoreExtensions) | — |
